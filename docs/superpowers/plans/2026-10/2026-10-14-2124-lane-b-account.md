## Overrides
1. **No migration/models**: `invitations`, `ad_connections` exist from W0-3 — skip the migration step in Task 2.
2. **Contract paths**: the public preview is `GET /invitations/{token}/preview` (not `/invitations/:token`); `GET /ad_connections` returns `{ connections: [...] }`; `GET /coordinator_names` returns `{ names: [...] }`; `createInvitation` request is `{ email, coordinator_name }` (role is always `coordinator`).
3. **Rack::Attack**: the initializer loads every `app/packs/*/config/rack_attack/*.rb` (so later lanes add their own throttles without editing it); this lane adds `account.rb` (signup and session throttles, 10/min/IP; disabled in test unless a spec enables it).
4. **Sample spend on connect**: call `Spend::SampleGenerator.call(agency:)` only when `defined?(Spend::SampleGenerator)` and the agency has leads (lane B-METRICS ships it); the request spec stubs the constant when absent.
5. **Data in specs**: `AlphaScenario.load!(agency)` instead of the importer; valid coordinator names for Alpha are `Dana Ortiz`, `Jess Kim`, `Priya Shah`.
6. **Fixture parity**: specs assert `GET /team` structure equals `contracts/examples/account/team.json` (ignoring ids/dates), `getAgency` equals `account/agency.json` shape, signup returns `Me`.
7. **Routes/isolation**: `app/packs/identity/config/routes/account.rb`; isolation entries (`/api/v1/team`, `/api/v1/invitations/:id` DELETE, `/api/v1/ad_connections`, `/api/v1/coordinator_names`, `/api/v1/agency`) in `spec/support/isolation/account.rb`; public routes registered with scope `:public`.
8. Request specs run with OpenAPI conformance on.

## Global Constraints
- Passwords ≥ 10 chars; invitation tokens stored as SHA-256 digests, 7-day expiry, single use; owner-only routes except signup / invitation preview / accept; signup never reveals other accounts except the `email_taken` response.
- Slug generation unique and never empty (`"!!!"` → `agency-xxxxxx`).
