## Overrides
1. Hook, formatters and the definition label (`definitionLabel(agency.qualified_milestone)`) come from Wave 0; fixture `contracts/examples/metrics/funnel.json` (Alpha: 10/5/4/3/2/1).
2. Bar tones: rows before the qualified row `dark`, the `qualified: true` row `brand` with `text-brand-text` name, rows after `success`.
3. Exit line = `"<100 − next.pct_of_previous>% leave here · reason, reason"`; the last row has none; when `exit_reasons` is empty show only the percentage.
4. Form drop-off section title "Where applicants stop in the form"; the highest bar `warning`; labels humanized (`pregnancy_history` → `Pregnancy history`).
- **Loading state (async uploads):** when the data is empty *and* `useCurrentSnapshot().data?.pending` is non-null, render `<LoadingYourData progress={pending.progress} />` instead of the empty state; when there is no snapshot and nothing pending, the owner gets the "Load your data" link to `/data` (coordinators: "Ask your agency owner to load data"). Test both with `?mock=loading` and `?mock=empty`.

## Responsive acceptance
- **Desktop:** header (title + `N leads` pill + subtitle), single card with six rows (name left, count + `% of previous` right, 10px bar, exit line), then the form card.
- **Mobile:** same card full width; count and percentage wrap under the name when narrow; bars keep 10px height; no horizontal scroll.
