## Global Constraints
- Implements `ShellProps` from `src/app/shell/types.ts` exactly; renders `overlays` once, `fab` bottom-right 24px, `topBarRight` items in the top bar.
- No fetching except `useCurrentSnapshot()` for the "Snapshot <date>" pill (formatted in the agency time zone).
- Nav comes only from the `nav` prop (role-filtered upstream; **skip items with `desktop === false`**, e.g. the mobile-only Ask tab); sections in order *Today*, *Insights*, *Operations*, *Agency* (only sections with items render).
- The prototype-only "view as" toggle is **not** built.

## Review Focus
- 30+ character agency name and user name truncate, never overflow the 224px sidebar.
- Active item is exact for `/` but prefix for others (`/channels/Facebook` keeps *Channels* active; `/` does not match everything).
- Keyboard: Tab order sidebar → top bar → main; the collapse button is labelled; ⌘K / Ctrl+K opens search even when focus is in an input? (only when not typing in a text field).
- Collapsed sidebar (64px) keeps tooltips (`title`) and the active state.
- Focus ring visible on every nav item.
