## Global Constraints
- Real backend (`E2E_API=real`), Anthropic stubbed via `E2E_STUB_ANTHROPIC=1` (canned `spec/fixtures/agent/e2e_answer.json`).
- Each journey runs in the Playwright `desktop` (1280×800) and `mobile` (390×844) projects and saves named screenshots in `e2e/screenshots/journeys/`.
- Tests reset state through `rails e2e:seed` (and `e2e:reset` below) in `beforeAll`; no test depends on another.

## Review Focus
- Mobile navigation paths differ (tab bar / More sheet / bottom sheets) — assert by role, not by CSS selectors.
- No flaky waits: use `expect(...).toBeVisible()` and network-idle on data screens only.
