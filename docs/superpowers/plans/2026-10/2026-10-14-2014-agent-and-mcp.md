**Goal:** A read-only, agency-scoped tool-calling agent (in-app panel) and an MCP server exposing the same five tools, with a spend ledger and privacy guarantees.

**Spec:** `docs/superpowers/specs/2026-10/2026-10-14-2013-agent-and-mcp-design.md`

**Depends on:** `2001-foundation`, `2003-snapshot-ingest`, `2005-metrics`, `2009-leads-workflow-api` merged (tools call `Metrics::*` and `Leads::NextActions`); for the UI also `2007-owner-insights-ui` (provides the no-op `useAgent`/`AgentProvider` this plan replaces) and `2010-leads-workflow-ui` (lead panel visibility, nav Ask tab).

**Architecture:** `Ai::Client` (only Anthropic touchpoint) + `Ai::Ledger`; `Agent::Tools` registry shared by `Agent::TurnRunner` and `Mcp::Server`; thin controllers; frontend `AgentProvider` + panel replace the no-op context.

**Tech Stack:** Rails 8, `anthropic` gem, WebMock, Rack::Attack · React 18 + TS, TanStack Query, Vitest, Playwright.

## Global Constraints
- `ANTHROPIC_API_KEY` from `.env` (copied from `../personal/appketing`); never committed, never logged.
- No tool takes an agency id; tools return aggregates, first names and verdicts only.
- Every model call records an `ai_usage_events` row (required `ledger:`).
- Specs never hit the network (WebMock `disable_net_connect!`).
- Models: `claude-sonnet-5-5` (agent), `claude-haiku-5-5` (cheap tasks); pricing values come from Anthropic's pricing page — **do not guess**; leave `cost_cents` nil if a model has no entry.

## Review Focus
- Model returns an unknown tool name or malformed tool input → tool_result `is_error`, loop continues, no 500.
- Anthropic 429/5xx/timeout → user sees a friendly error, turn lock released, no orphan `tool_use` in stored history.
- Prompt-injection text inside data (campaign name "ignore previous instructions…") never changes tool access or leaks other data.
- User asks for another agency's data or a lead's health answers → polite refusal, nothing leaked.
- `forecast_spend` with zero spend or zero qualified → explanation, not NaN/Infinity.
- Two quick sends from the same user → second gets 409, UI re-enables correctly.

```ruby
module Ai
  class Client
    TIMEOUT = 45
    attr_reader :model
    def self.config = @config ||= YAML.load_file(Rails.root.join("config/ai_models.yml"), aliases: true).fetch(Rails.env.to_s) { {} }
    def initialize(task)
      @task = task.to_s

    end

    def converse(messages:, system:, tools: [], max_tokens: 1024, ledger:)
      http = Anthropic::Client.new(api_key: ENV.fetch("ANTHROPIC_API_KEY", "test"), timeout: TIMEOUT)
      params = { model: @model, max_tokens: max_tokens, system: system, messages: messages }
      params[:tools] = tools if tools.any?
      response = http.messages.create(**params)
      usage = { input_tokens: response.usage.input_tokens, output_tokens: response.usage.output_tokens }
      ledger.record!(model: @model, usage: usage)          # before parsing, never skipped
      { content: response.content.map { |b| JSON.parse(b.to_json) }, stop_reason: response.stop_reason.to_s, usage: usage }
    end
  end
end
```

**Interfaces — Produces:**

Schemas: `range` enum `["30d","90d","12m"]` (default `30d`); `get_channel_performance` optional `channel`; `get_next_actions` optional `coordinator` (ignored for coordinator users); `forecast_spend { monthly_budget_cents: integer ≥ 0 (required), channel?: string, months?: integer 1–12 default 3 }`.
Behavior: `get_funnel` = `Metrics::Funnel` + `Metrics::Summary[:kpis]`; `get_channel_performance` = `Metrics::Channels` (or `ChannelDetail` when `channel` given); `get_dropoff_reasons` = `{ form_dropoff:, exit_reasons: stages.map { {stage, exit_reasons} } }`; `get_next_actions` = queue counts + first 5 items per queue as `{ first_name, age_label, reason }` (strip surnames; reason stays), owner may filter `coordinator`; `forecast_spend`: uses trailing 90 days: `cpq = spend / qualified` (overall or channel); returns `{ basis_days: 90, cost_per_qualified_cents:, expected_qualified_per_month: (budget / cpq).round(1), months:, expected_qualified_total:, caveats: ["Estimate from the last 90 days…", ("Spend is sample data" if source sample)] }` or `{ error: "no_spend_data" | "no_qualified_leads", message: }`.
Roles: owner → all five; coordinator → only `get_next_actions` (forced to own coordinator name); other names → `Error("tool_not_allowed")`.
