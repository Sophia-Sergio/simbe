## Global Constraints
- Presentational only: **no data fetching, no router, no hooks from `src/api`**. Props in, markup out.
- Tokens only; the single allowed raw-hex place is `ChannelTile` (placeholder channel colors from the handoff).
- Every chart/ring has `role="img"` with a text alternative and always prints its values (no color-only meaning).
- Mobile: `Table` renders stacked cards below 860px.

## Review Focus
- `null`/`undefined` values render `—`, never `NaN`/`$0`/`+0%`.
- Bars with value 0 or max 0 don't divide by zero; percentages clamp to 0–100.
- Very long labels truncate with ellipsis and keep a `title`.
- Ring with `total = 0` renders an empty state, not `NaN%`.
