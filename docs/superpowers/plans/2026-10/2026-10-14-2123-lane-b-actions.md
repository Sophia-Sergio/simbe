1. **No migration**: `action_completions` and `ActionCompletion` exist from W0-3 — Task 4 is only the service, serializer and controllers.
2. **Data in specs**: `AlphaScenario.load!(agency)` / `(agency, :v2)`; the "resets when a newer snapshot is loaded" example loads v2 the same way.
3. **Coordinator stats**: use the corrected expectations already in Task 5 (Dana's first-reply median `22.5`, `needs_support` via the stubbed threshold, detail returns `needs_action` for L3/L4/L10).
4. **Fixture parity**: a spec asserts `GET /next_actions` (owner) equals `contracts/examples/next-actions/next-actions.json`, `GET /coordinators` equals `coordinators/list.json`, `GET /coordinators/Dana%20Ortiz` equals `coordinators/detail-dana.json` after JSON round-trip.
5. **Lead lookup** for completions uses `Leads::Access.relation(user).find(id)` (404 outside scope) and validates the lead is currently in the named queue via `Leads::Queues`.
6. **Routes/isolation**: `app/packs/leads/config/routes/next_actions.rb` and `…/coordinators.rb` (`/next_actions/:lead_id/:queue/completion` POST+DELETE; coordinator name is a URL-encoded path segment); isolation entries in the matching files under `spec/support/isolation/`.
7. Request specs run with OpenAPI conformance on.

8. **Real-data oracle** (`spec/real_data/actions_golden_spec.rb`, tag `:real_data`): for `harbor` and `lakeside` assert against `Golden.agency(slug)`: the owner's `GET /next_actions` queue counts (sum of `items` per queue, nothing completed) equal `queues_all_leads` (Harbor 6/22/3/3, Lakeside 6/149/8/17); `GET /coordinators` rows (stats cover **all leads in the snapshot**) equal `coordinators_all_time` for every coordinator — `leads`, `share_pct`, `qualified`, `qualified_rate`, `first_reply_minutes` (median, golden `first_reply_minutes_median`), `overdue` (queues 1–3 older than 24 h); Dana Ortiz = 2,252 leads / 63.8% in Harbor; a coordinator session for Dana sees only her own items and the sum over all four coordinators equals the owner total. Rounding follows the oracle (half-up minutes; `percentile_cont(0.5)` median).

## Global Constraints
- Coordinators: own queues only, never `/coordinators*` (403); completions keyed by `lead_external_id + snapshot_as_of` so a new snapshot resets the day; queue keys outside `Leads::Queues::KEYS` → `422 bad_queue`; POST/DELETE are idempotent.
