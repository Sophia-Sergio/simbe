## Global Constraints
- Secrets only in GitHub/Fly secret stores; `FLY_API_TOKEN` lives in the GitHub **environment `production`**. No secret, export, `.env` or key in git (the `guards` job enforces it).
- **Fly machine must stay up while background jobs run**: unlike appketing's scale-to-zero, Simbe's imports run as jobs inside the web process (Solid Queue in Puma), so `auto_stop_machines = "off"`, `min_machines_running = 1`.
- The deploy job runs only on `main`, only after every required job passed, and never in parallel with itself.
- Workflows pass user-controlled values (branch names, PR titles) through `env:`, never inline in `run:` (actionlint enforces this).

## Review Focus
- A PR from a `lane/*` branch that edits an unowned file fails `ownership_check`; a `ccr`-labelled PR touching only `contracts/**` passes.
- `docker build` works from the repo root without secrets; the SPA build in the image uses `VITE_API_MODE=real` and does **not** ship `mockServiceWorker.js`.
- Any unknown `/api/*` or `/mcp/*` path never falls through to the SPA HTML (JSON 404 instead); a missing `/assets/*.js` is a 404, not HTML.
- `e2e_real` never needs the real exports (they are never in CI): it uploads the synthetic export through the browser.
- Losing `AR_ENCRYPTION_*` keys makes screener answers unreadable — the runbook makes backing them up a blocking step.

## Task 2: Production image and entrypoint

**Files:** `Dockerfile`, `.dockerignore`, `bin/fly-start`, `bin/docker-entrypoint`.

- [ ] **Step 1: `Dockerfile`** (build context = repo root; mirrors appketing's structure)
```dockerfile
# syntax=docker/dockerfile:1
# check=error=true
ARG RUBY_VERSION=3.3.6          # must match .ruby-version (verify in CI via bin/ci-parity)
ARG NODE_VERSION=22

# ---------- SPA build ----------
FROM docker.io/library/node:${NODE_VERSION}-bookworm-slim AS web
WORKDIR /web
COPY package.json package-lock.json ./
RUN npm ci
COPY frontend/ ./
COPY contracts/ /contracts/
ENV VITE_API_MODE=real
RUN npm run build && rm -f dist/mockServiceWorker.js

# ---------- Rails base ----------
FROM docker.io/library/ruby:${RUBY_VERSION}-slim AS base
WORKDIR /rails
RUN apt-get update -qq && \
    apt-get install --no-install-recommends -y curl libjemalloc2 libpq5 postgresql-client && \
    ln -s /usr/lib/$(uname -m)-linux-gnu/libjemalloc.so.2 /usr/local/lib/libjemalloc.so && \
    rm -rf /var/lib/apt/lists /var/cache/apt/archives
ENV RAILS_ENV="production" BUNDLE_DEPLOYMENT="1" BUNDLE_PATH="/usr/local/bundle" BUNDLE_WITHOUT="development:test" \
    LD_PRELOAD="/usr/local/lib/libjemalloc.so" RAILS_SERVE_STATIC_FILES="true" RAILS_LOG_TO_STDOUT="true" SOLID_QUEUE_IN_PUMA="true"

# ---------- Gems + app ----------
FROM base AS build
RUN apt-get update -qq && apt-get install --no-install-recommends -y build-essential git libpq-dev libyaml-dev pkg-config && \
    rm -rf /var/lib/apt/lists /var/cache/apt/archives
COPY .ruby-version Gemfile Gemfile.lock ./
RUN bundle install && rm -rf ~/.bundle/ "${BUNDLE_PATH}"/ruby/*/cache "${BUNDLE_PATH}"/ruby/*/bundler/gems/*/.git && \
    bundle exec bootsnap precompile --gemfile
COPY  ./
COPY --from=web /web/dist/ ./public/
RUN chmod +x bin/fly-start bin/docker-entrypoint 2>/dev/null || true
RUN bundle exec bootsnap precompile app/ lib/

# ---------- Final image (non-root) ----------
FROM base
RUN groupadd --system --gid 1000 rails && useradd rails --uid 1000 --gid 1000 --create-home --shell /bin/bash
USER 1000:1000
COPY --chown=rails:rails --from=build "${BUNDLE_PATH}" "${BUNDLE_PATH}"
COPY --chown=rails:rails --from=build /rails /rails
ENTRYPOINT ["/rails/bin/docker-entrypoint"]
EXPOSE 8080
CMD ["./bin/fly-start"]
```
`bin/fly-start` (the image copies `` to `/rails`, so it runs as `./bin/fly-start`): `#!/bin/bash -e` / `exec ./bin/thrust ./bin/rails server` (Thruster listens on `HTTP_PORT=8080`, Rails on `TARGET_PORT=3000`; Solid Queue runs inside Puma). `bin/docker-entrypoint`: `export LD_PRELOAD=...`, then `exec "$@"` (migrations run in Fly's release command, not here). `.dockerignore`: `.git`, `.worktrees`, `node_modules`, `frontend/node_modules`, `frontend/dist`, `handoff/takehome/exports`, `**/.env*`, `**/*.csv` except `spec/fixtures`, `log`, `tmp`, `storage`, `coverage`, `e2e/screenshots`, `.superpowers`, `docs`.

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [ main ]
  schedule:
    - cron: "0 7 * * *"   # nightly e2e_real

permissions:
  contents: read
  actions: read
  pull-requests: read

concurrency:
  group: ci-${{ github.event.pull_request.number || github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

env:
  RUBY_VERSION_FILE: .ruby-version
  NODE_VERSION: "22"
  # Non-secret dummy keys so Active Record Encryption works in CI (never use these anywhere else).
  AR_ENCRYPTION_PRIMARY_KEY: ci-primary-key-0123456789abcdef0123456789abcdef
  AR_ENCRYPTION_DETERMINISTIC_KEY: ci-deterministic-key-0123456789abcdef01234567
  AR_ENCRYPTION_KEY_DERIVATION_SALT: ci-salt-0123456789abcdef0123456789abcdef

jobs:
  decide:
    name: Decide whether CI already ran
    runs-on: ubuntu-latest
    outputs:
      run_ci: ${{ steps.decide.outputs.run_ci }}
    steps:
      - name: Skip CI when this commit already passed on a merged PR
        id: decide
        uses: actions/github-script@v7
        with:
          script: |
            if (context.eventName !== 'push' || context.ref !== 'refs/heads/main') {
              core.setOutput('run_ci', 'true'); return
            }
            const { data: prs } = await github.rest.repos.listPullRequestsAssociatedWithCommit({
              owner: context.repo.owner, repo: context.repo.repo, commit_sha: context.sha })
            const merged = prs.find((pr) => pr.merged_at)
            if (!merged) { core.setOutput('run_ci', 'true'); return }
            const { data: runs } = await github.rest.actions.listWorkflowRuns({
              owner: context.repo.owner, repo: context.repo.repo, workflow_id: 'ci.yml', head_sha: merged.head.sha, per_page: 20 })
            const passed = runs.workflow_runs.some((r) => r.event === 'pull_request' && r.conclusion === 'success')
            core.setOutput('run_ci', passed ? 'false' : 'true')

  contract:
    name: Contract
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}", cache: npm, cache-dependency-path: package-lock.json }
      - run: cd frontend && npm ci
      - name: Bundle and lint the OpenAPI contract (validates every example)   # parity
        run: cd frontend && npm run contract
      - name: Generated API types are up to date   # parity
        run: cd frontend && npm run types && git diff --exit-code app/javascript/api/generated
      - name: No two lanes own the same files   # parity
        run: bash docs/superpowers/parallel/check-ownership.sh

  brakeman:
    name: Brakeman
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { working-directory: backend, bundler-cache: true }
      - run: cd backend && bundle exec brakeman -q --no-pager   # parity

  bundler_audit:
    name: Bundler audit
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { working-directory: backend, bundler-cache: true }
      - run: cd backend && bundle exec bundler-audit check --update   # parity

  npm_audit:
    name: npm audit
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}" }
      - run: cd frontend && npm audit --audit-level=high   # parity

  knip:
    name: Unused frontend code
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}", cache: npm, cache-dependency-path: package-lock.json }
      - run: cd frontend && npm ci
      - run: cd frontend && npx knip   # parity

  lint_backend:
    name: Lint backend
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    env:
      RUBOCOP_CACHE_ROOT: tmp/rubocop
    steps:
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { working-directory: backend, bundler-cache: true }
      - uses: actions/cache@v4
        with:
          path: tmp/rubocop
          key: rubocop-${{ runner.os }}-${{ hashFiles('.ruby-version', '.rubocop.yml', 'Gemfile.lock') }}
      - run: cd backend && bundle exec rubocop --format github --format simple   # parity
      - name: Architecture boundaries
        env: { DATABASE_URL: "postgres://unused:unused@127.0.0.1/unused" }
        run: cd backend && bundle exec rails boundaries:check   # parity

  lint_frontend:
    name: Lint frontend
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}", cache: npm, cache-dependency-path: package-lock.json }
      - run: cd frontend && npm ci
      - run: cd frontend && npm run lint   # parity
      - run: cd frontend && npm run typecheck   # parity

  test_backend:
    name: Backend tests
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env: { POSTGRES_USER: postgres, POSTGRES_PASSWORD: postgres }
        ports: [ "5432:5432" ]
        options: --health-cmd="pg_isready -U postgres" --health-interval=10s --health-timeout=5s --health-retries=5
    steps:
      - run: sudo apt-get update && sudo apt-get install --no-install-recommends -y libpq-dev
      - uses: actions/checkout@v4
      - uses: ruby/setup-ruby@v1
        with: { working-directory: backend, bundler-cache: true }
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}", cache: npm, cache-dependency-path: package-lock.json }
      - name: Bundle the OpenAPI contract for conformance checks
        run: cd frontend && npm ci && npm run contract
      - name: RSpec (OpenAPI conformance on)   # parity
        env:
          RAILS_ENV: test
          DATABASE_URL: postgres://postgres:postgres@localhost:5432
        run: |
          cd backend
          bundle exec rake 'parallel:create[2]' 'parallel:load_schema[2]'
          bundle exec parallel_rspec spec -n 2 --group-by runtime --allowed-missing 100
          bundle exec rake contract:coverage | tee ../contract-coverage.txt
      - uses: actions/upload-artifact@v4
        if: always()
        with: { name: contract-coverage, path: contract-coverage.txt, if-no-files-found: ignore }

  test_frontend:
    name: Frontend tests
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:

        run: cd frontend && npm test

  e2e_mock:
    name: E2E (mock API, desktop + mobile)
    needs: decide
    if: needs.decide.outputs.run_ci == 'true'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: "${{ env.NODE_VERSION }}", cache: npm, cache-dependency-path: package-lock.json }
      - run: cd frontend && npm ci && npx playwright install --with-deps chromium
      - name: Start the Vite dev server in mock mode
        run: |
          cd frontend
          VITE_API_MODE=mock npm run dev -- --host 127.0.0.1 --port 5173 &
          npx --yes wait-on http://127.0.0.1:5173 --timeout 60000
      - name: Playwright (desktop + mobile projects)   # parity
        env: { E2E_BASE_URL: "http://127.0.0.1:5173" }
        run: cd frontend && npx playwright test
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: e2e-mock-screenshots
          path: |
            e2e/screenshots
            frontend/test-results
          if-no-files-found: ignore

  e2e_real:
    name: E2E (real API)
    needs: decide
    # main, nightly, or PRs labelled `e2e`; not required until Wave 3 (W3-1) flips continue-on-error off
    if: >
      needs.decide.outputs.run_ci == 'true' &&
      (github.event_name == 'schedule' || github.ref == 'refs/heads/main' || contains(github.event.pull_request.labels.*.name, 'e2e'))

    continue-on-error: true
    services:
      postgres:
```
