## Overrides
1. **No migration/model for spend** (Task 1): `ad_spend_daily` and `AdSpendDay` exist from W0-3; implement `Spend::SampleGenerator`, `rake spend:sample[slug]` and `AlphaSpend` only.
2. **Qualified column** comes from `AgencyMilestones::COLUMNS` (W0-3), not a local constant; `Metrics::Base::QUALIFIED_COLUMNS` just aliases it.
3. **Data in specs**: replace every `Snapshot::Importer.call(agency: agency, dir: AlphaScenario.copy_dir)` with `AlphaScenario.load!(agency)`.
4. **Agency endpoints are not here** (`GET/PATCH /agency` belong to lane B-ACCOUNT): drop the `AgenciesController` and the request example "changes numbers when the owner changes the definition" from Task 7; the service-level "follows a changed definition immediately" specs (which use `agency.update!`) stay and cover it.
5. **Routes/isolation**: `backend/config/routes/metrics.rb` (`get "metrics/summary"`, `…/funnel`, `…/channels`, `…/channels/:channel`, `get "recommendations"`), isolation entries in `backend/spec/support/isolation/metrics.rb`.
6. **Contract**: payload keys exactly per `contracts/openapi/schemas/metrics.yaml` (e.g. `cost_by_channel[].cost_per_qualified_cents`, `kpis.cost_per_qualified.value_cents`); request specs run with OpenAPI conformance on; the Alpha expectations must equal `contracts/examples/metrics/*.json` (a spec asserts `summary`, `funnel`, `channels`, `channel-facebook`, `recommendations` responses equal those fixtures after JSON round-trip).
