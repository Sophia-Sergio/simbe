## Overrides
1. **No spend** (amended 2026-10-19): the exports carry no ad spend, so there is no `ad_spend_daily`, `Spend::SampleGenerator`, `rake spend:sample` or `AlphaSpend`. Channels compare on leads and qualified rate.
2. **Qualified column** comes from `AgencyMilestones::COLUMNS` (W0-3), not a local constant; `Metrics::Base::QUALIFIED_COLUMNS` just aliases it.
3. **Data in specs**: replace every `Snapshot::Importer.call(agency: agency, dir: AlphaScenario.copy_dir)` with `AlphaScenario.load!(agency)`.
4. **Agency endpoints are not here** (`GET/PATCH /agency` belong to lane B-ACCOUNT): drop the `AgenciesController` and the request example "changes numbers when the owner changes the definition" from Task 7; the service-level "follows a changed definition immediately" specs (which use `agency.update!`) stay and cover it.
5. **Routes/isolation**: `app/packs/metrics/config/routes/metrics.rb` (`get "metrics/summary"`, `…/funnel`, `…/channels`, `…/channels/:channel`, `get "recommendations"`), isolation entries in `spec/support/isolation/metrics.rb`.
6. **Contract**: payload keys exactly per `contracts/openapi/schemas/metrics.yaml` (e.g. `rows[].rate`, `kpis.qualified_rate.value`); request specs run with OpenAPI conformance on; the Alpha expectations must equal `contracts/examples/metrics/*.json` (a spec asserts `summary`, `funnel`, `channels`, `channel-facebook`, `recommendations` responses equal those fixtures after JSON round-trip).

7. **Real-data oracle** (`spec/real_data/metrics_golden_spec.rb`, tag `:real_data`, skipped when the exports are absent): for `harbor` (Pacific, *attended a consult*) and `lakeside` (Central, *reached records*) create the agency from `RealData::CONFIG`, `RealData.load!` it, sign in as its owner and assert against `Golden.agency(slug)`: `GET /metrics/summary?range=30d|90d|12m` → `kpis.leads.value`, `kpis.qualified.value`, `kpis.qualified_rate.value`, `kpis.leads.previous` (golden `summary.<range>.leads/qualified/qualified_rate/previous_leads`); changing `agency.qualified_milestone` to each of the four milestones reproduces `summary.12m.qualified_by_milestone`; `GET /metrics/funnel?range=12m` → `stages[].count`, `pct_of_previous` and `exit_reasons` equal `funnel_12m` (note: **reasons are the real labels** such as `BMI`, `No response`, blank → the outcome); `form_dropoff` equals `form_dropoff_12m`; `GET /metrics/channels?range=12m` → per-channel `leads`, `qualified`, `rate` equal `channels_12m` and `insights.unattributed` / `insights.out_of_area` (count, pct, `main_states`) equal `insights_12m`. Harbor 12m = all 3,530 leads; Lakeside 12m = 14,860 (the exports span ~2 years).
