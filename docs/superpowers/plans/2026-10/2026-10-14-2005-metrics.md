# Metrics API Implementation Plan

> **Detail reference, not executed directly.** The work in this plan is sliced into parallel lanes — see [`docs/superpowers/parallel/README.md`](../../parallel/README.md). Lane plans execute specific tasks of this plan with explicit overrides (data via `AlphaScenario.load!`, hooks/kit/shell from Wave 0, routes via per-lane files, contract paths per `contracts/openapi`). Where this plan differs from a lane plan or the contract, **the lane plan and `contracts/` win**.

> **For Cursor / OpenCode:** Implement task-by-task. Follow `docs/conventions/`. Stop if blocked — do not replan silently. Steps use checkbox (`- [ ]`) syntax. **Commit after every task** (`feat(metrics): task N – <title>`) after `make verify`.

**Goal:** Agency-scoped, SQL-aggregated KPIs, funnel, channel and recommendation endpoints driven by the agency's own definition of "qualified".

**Spec:** `docs/superpowers/specs/2026-10/2026-10-14-2004-metrics-design.md`

**Depends on:** `2026-10-14-2001-foundation` and `2026-10-14-2003-snapshot-ingest` merged (Lead, LeadFact, Snapshot, AlphaScenario, ExportBuilder). **Unblocks:** owner-insights UI, agent/MCP.

**Architecture:** One `Metrics::*` class per question, all inheriting `Metrics::Base` (range windows, qualified column whitelist, bind-param SQL, caching). A thin `MetricsController` calls them. Spend comes from `ad_spend_daily` (sample generator for now).

**Tech Stack:** Rails 8, Postgres 16 SQL (CTEs), RSpec.

## Global Constraints
- SQL always binds `:agency_id`; the qualified column is picked from `Metrics::Base::QUALIFIED_COLUMNS`, never interpolated from input.
- Owner-only endpoints. Rates with `leads < 30` get `low_sample: true`.
- Numbers use `as_of` of the latest snapshot, never `Time.current`.

## Review Focus
- Agency with no snapshot → empty-state payload (`snapshot: null`, zero KPIs), not a 500.
- Zero qualified → `cost_per_qualified: null`, rate `0.0`, no divide-by-zero.
- Range with zero leads in the previous window → `delta: null`.
- Spend rows outside the range or other agencies must not leak into totals.
- Changing `qualified_milestone` changes numbers on the very next call (cache key).

class Metrics::Base

  def window                              # { from:, to:, prev_from:, prev_to: } (UTC Time), to = snapshot.as_of; current window is `>= from AND <= to`, previous is `>= prev_from AND < from`

end
