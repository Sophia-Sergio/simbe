## Overrides
1. State, the Cmd/Ctrl+K listener and "opening search closes the lead panel" already live in `@/app/searchPalette` (Wave 0). This lane renders the palette and handles selection (`useLeadPanel().open(id)` then `close()`).
2. The input is a `combobox` with `aria-activedescendant`; results are `option`s (max 8): name, channel pill, status pill; ↑/↓ move the active option, Enter opens it, Esc closes; "No matches" for empty results; searching starts at 2 characters (the hook enforces it) and shows a Skeleton while loading.
3. Coordinators search only their own leads (the API scopes it; the mock does too) — assert in a test with a coordinator session that results never include other coordinators' names.
4. `%` and `_` are literal (mock returns `[]` for `%`); text is escaped (no HTML injection).

## Responsive acceptance
- **Desktop:** centered modal (max 480px, `rounded-modal`) near the top; opens with ⌘K/Ctrl+K and from the top-bar button.
- **Mobile:** bottom-sheet modal (kit `Modal` variant) with the input focused and the on-screen keyboard not hiding results (results area scrolls, max-height `60vh`); opened from the mobile top bar search affordance if the shell exposes it (otherwise only programmatically — note in the PR).
