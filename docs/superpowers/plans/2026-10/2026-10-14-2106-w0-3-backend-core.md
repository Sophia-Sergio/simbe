## Global Constraints
- Every tenant table has `agency_id` + an index starting with `agency_id`; children cascade from `leads`.
- `unscoped` only in `app/services/snapshot/**` (boundary rule). `AlphaScenario` lives in `spec/` and may use `unscoped`.
- API JSON matches `contracts/openapi/**`; request specs run with conformance on.
- **Lanes add no migrations.** If this plan misses a column a lane needs, that lane files a CCR/ownership issue.

## Review Focus
- Fresh `db:create db:migrate` on empty Postgres, and `db:schema:load`, both work.
- `AlphaScenario.load!` twice for the same agency leaves identical counts (it replaces).
- Loading Alpha for two agencies never mixes rows.
- `Leads::Queues` returns `[]` for an agency without a snapshot.
- Session cookie forged/expired → 401, never 500.
