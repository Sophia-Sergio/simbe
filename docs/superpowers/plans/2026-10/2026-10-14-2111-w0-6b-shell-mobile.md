## Global Constraints
- Implements `ShellProps`; renders `overlays` once; **never renders `fab`** (the agent opens from the Ask tab).
- Tabs come from `nav[].mobile.tab` (sorted by `order`), More rows from `nav[].mobile.more`; owner tabs Home/Pipeline/Channels/Ask/More, coordinator Next actions/My leads/Ask — that composition is decided by the features' `nav` declarations, so the shell must handle **any** list of ≤5 tabs and add the "More" tab only when there are `more` items.
- Main padding `18px 14px 110px`; bottom bar respects `env(safe-area-inset-bottom)`; no horizontal scroll at 360px.

## Review Focus
- Tab bar covers content only by the reserved 110px padding; last list item stays reachable.
- More sheet closes on route change, on Esc and on scrim tap; opening it while an overlay (lead panel) is open is impossible because the overlay is full screen above the bar.
- The active tab for nested routes (`/channels/Facebook` → Channels); the More tab is active when the current route belongs to a `more` item.
- Action tabs (Ask) call their handler instead of navigating and never show as "active" unless their overlay is open.
- Title in the top bar updates on navigation and truncates.
